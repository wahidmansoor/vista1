# OncoVista
This is a web app designed for oncology professionals, providing decision support for chemotherapy, outpatient, and palliative care.

## Clinical Decision Support (CDS)

The Disease Progress module includes a deterministic CDS Advisor for oncology:
- **Deterministic Engine**: Rule-based protocol matching against a local dataset of 42 protocols.
- **Safety-First UI**: Explicit contraindication blocking and eligibility gating.
- **Clinician-Centric**: Rationale disclosure and mandatory review notices.
- **Auditable**: No AI inference in the primary matching logic.

*Note: This is a support tool and does not replace medical professional judgment.*
